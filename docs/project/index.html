For EZ-Flash Omega and Omega Definitive Edition

A familiar new home for your Game Boy Advance.

DS Style is a complete launcher overhaul inspired by the Nintendo DS, created in celebration of the Game Boy Advance's 25th anniversary.

Download DS Style Open the user guide Watch the tutorial

Designed for everyday play.

A faithful DS-inspired interface, thoughtful shortcuts, flexible artwork, and broad personalisation without giving up the features of the official kernel.

Core experience

  • Animated Nintendo DS-inspired start screen
  • List, horizontal carousel, and vertical carousel views
  • Recently played and favourite game collections
  • Refined navigation and quality-of-life improvements

Appearance

  • All 16 Nintendo DS colour options
  • Light and dark presentation modes
  • Title-screen and box-art thumbnails
  • Custom artwork for games, files, and folders

Launch options

  • Favourite and last-played games on the start screen
  • Configurable boot behaviour
  • Quick-start hotkey
  • Optional direct launch without the game menu

Personalisation

  • Custom username in the top bar
  • Toggleable interface sounds
  • Editable themes, colours, images, sounds, and text
  • Readable settings stored on the SD card

Kernel features

  • Retains the functionality of the official kernel
  • PogoShell plug-in support
  • Save backups
  • Dedicated builds for both supported cartridges

Make the library yours.

Choose a colour, switch presentation modes, and browse with title artwork or box art. DS Style keeps the interface recognisable while leaving room for a personal touch.

Two tools. Your version.

DS Style already includes ready-to-use artwork. These optional desktop tools make deeper personalisation approachable without editing the kernel by hand.

DS Style Customiser

Build a personalised kernel with your own themes, colours, images, interface sounds, text, languages, and supported launcher layouts.

Thumbnail Scraper
